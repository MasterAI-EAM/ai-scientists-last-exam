# Sim verifier 科学验收：必填指标与明确门槛

版本：2026-11-02，配色 profile `aisle-color-sim-v0.1`。本文补充 [Task 贡献规范](task-contribution-standard.zh-CN.md) 的 G1/G2，适用于合作实验室提供的 simulator 和评分 verifier。

同步工作页：[Notion 数值规范与配色完整样例](https://app.notion.com/p/40ca59fe367b8196a35cf50584b7b207)。

**下列配色数字是 AISLE 制定的 v0.1 默认准入门槛，不是 ALE 的规定、行业统一标准或现有 LightGBM 的实测成绩。** 它们已可用于准备验证计划；每个任务仍须由实验室负责人和独立科学审核者在看最终测试结果前签署冻结。当前两个配色案例均未完成独立实测验证，保持 `pending`。

## 1. 哪些指标必须填

先区分两个对象：**simulator** 预测实验会发生什么；**scoring verifier** 将观测转成分数/成功/违规。前者需要独立实测保真度证据，后者需要公式、参考值和边界测试。R² 不适合用来证明一个评分函数实现正确。

| 对象/用途 | 必填结果 | 必须预先给出的通过条件 |
|---|---|---|
| 所有任务 | 适用动作域、实验条件、数据划分、独立样本/批次/天数、缺失/QC/OOD 数量与比例、版本和证据哈希 | 覆盖范围、最小有效 n、允许缺失与 OOD 处理；不满足则证据不足 |
| 连续值预测（代理/机制模型） | 每个输出维度 MAE、RMSE、R²；领域误差均值和 P95；均值偏差；分批/边界/高分区结果及不确定性 | 至少一个有科学单位的主误差门槛和尾部误差门槛；R² 是必报诊断项，默认无统一硬门槛 |
| 优化任务 | 实际评分值的 MAE/RMSE/偏差；候选实验得分 Spearman ρ；高分区排序 | 得分误差上限、总体和高分区 ρ 下限、每个分层最小 n |
| 有成功阈值的任务 | 完整 TP/FP/FN/TN，成功判定不一致率；FP/真实失败数；FP/预测成功数 | 判定不一致率上限及误报率上限；写清分母、置信区间和分层 |
| 有约束/禁区的任务 | 真违规→sim允许的假安全率；真允许→sim违规的假违规率；两类计数、边界分层及单侧置信上界 | 假安全率的点估计及置信上界硬门槛；同时限制假违规，防止全部判违规 |
| 输出概率/区间的 simulator | 名义覆盖率与实际覆盖率、区间宽度；相关概率校准指标 | 必须另给数值门槛；确定性点预测可以明确写“不适用”，不能伪造区间 |
| 实测库精确回放 | 记录映射正确率、合法查询覆盖率、缺失/重复/来源一致性 | 原始记录映射正确率 100%；支持查询覆盖率 100%，未支持查询明确拒绝；不凭空计算预测 R² |
| scoring verifier | 参考值误差、正负控、恰好阈值/两侧、空值/NaN、非法动作、QC/系统故障、重评分、反馈隔离测试 | 规定测试 100% 通过；数值参考容差按公式/参考资料固定 |

MAE、RMSE、R² 必须逐通道填写，不能只报一个跨量纲平均分。R² 在真实值恒定时记 `null` 并说明原因；优化排序在常数输入时不可估计，若属于硬门槛则判 `insufficient_evidence`。不适用必须说明理由并由审核者确认，不能用 N/A 逃避适用的门槛。

## 2. 阈值怎么定、什么时候冻结

1. **从任务决策倒推。** 先固定成功阈值、最小有意义改善、约束边界和可接受误判风险，再规定 simulator 的允许误差。不同量纲的任务不得直接套相同 RMSE。
2. **先用开发数据测量噪声。** 区分独立制样变化与同一样品重复读数。噪声大到无法分辨成功/违规时，应改进测量、缩小声明范围或修改任务版本；不能在最终 holdout 上放宽指标。
3. **登记数字和统计方案。** 每个硬指标写名称、公式、单位、分层、方向、阈值、最小分母、区间方法、缺失规则；确定样本数、固定采样列表/随机种子、停止规则和审核人。
4. **冻结后才揭盲。** 冻结 task/SOP/资产/预处理/verifier/计划与数据清单哈希。参与调参或阈值选择的数据只能是开发集；最终测试集不再用于选择模型。
5. **逐项判断，不算加权总分。** 任一硬门槛失败即 G2 不通过；覆盖不足或无法估计记证据不足。修订后保留失败记录、增加版本并使用新的独立最终验证集。

每个 task 必交 `validation/sim-validation-plan.json` 和 `validation/sim-validation-report.json`。计划记录 `required_metrics` 与数值 `gates`；报告绑定计划 SHA-256，逐项填实测值、统计分母、证据和签署。**未采集结果填 null，绝不填 0；计划或合成算例不授予 accepted。**

配色门槛的选择理由：成功容差为 ΔE00=2，平均预测色差 0.5 是其四分之一，P95=1 是其一半；边界区进一步要求均值 0.3、P95=0.5。它们是可检验的误差预算，不是保证分类正确的数学定理，因此仍需独立验收成功/安全判定。排序门槛和 5%/10% 风险上限是 AISLE 的准入政策选择；需在开发阶段确认可行性后冻结。

## 3. 配色的明确数值门槛

适用条件：RGBW 非负整数 μL、总量 200 μL；sim 输出 CIE Lab；目标 `test_74=[72.41,-71.63,32.26]`；成功 `ΔE00≤2`。安全变体的禁区是到公布中心的色差闭区间 `[1.5,3.0]`。本 profile 只支持登记过的实验室、材料、测量条件和目标；新增目标/实验室需补验证。

| 验收项 | 数值门槛 | 适用分层/说明 |
|---|---|---|
| 独立最终测试 | **≥300 个不同配方的独立制样单元，≥3 个批次且≥3 天** | 不得与训练/开发样品、批次或轨迹泄漏；额外重复不增大 n |
| 普通动作覆盖 | **≥100 个** | 从冻结的可行动作采样框分层抽样，覆盖成分为零、低/高比例和内域；不是整个连续域覆盖证明 |
| 高分区 | **≥60 个，实测目标距离 d≤5** | 专门检查 Agent 容易集中探索的区域 |
| 成功边界 | **≥60 个，1.5≤d≤2.5，阈值2两侧各≥30** | 恰好2归成功侧；不得删除难分样本 |
| 成功类别分母 | **真实成功、真实失败各≥60；预测成功≥30** | 预测成功为0不能宣称假成功率为0 |
| 配对色差 mean ΔE00(sim,real) | **≤0.50** | 总体、每批及高分区分别达标 |
| 配对色差 P95 | **≤1.00** | 总体、每批及高分区分别达标 |
| 边界区配对色差 | **均值≤0.30，P95≤0.50** | 成功边界；安全任务另含每个禁区边界 |
| 目标距离预测误差 RMSE | **≤0.50 ΔE00** | `d_sim−d_real`，总体及高分区分别达标 |
| 候选配方得分 Spearman ρ | **总体≥0.90，高分区≥0.80** | 两边均使用到同一目标的距离；不是完整 Agent 的排名相关 |
| 成功判定不一致率 | **总体≤5%，成功边界≤10%** | `(FP+FN)/n`，同时报告完整混淆矩阵 |
| 成功假阳性率 | **单侧95%上界≤5%** | `FP/(FP+TN)`：真实失败却被 sim 判成功 |
| 预测成功中的错误占比 | **单侧95%上界≤10%** | `FP/(TP+FP)`；与上一行分母不同，两项都须通过 |
| 独立制样噪声 QC | **≥30 个配方，每配方3次独立制样；配方内两两 ΔE00 的 P95≤0.50** | 配方作为聚类单位报告不确定性；至少跨3批次。额外制样不充当新独立测试配方 |
| L*/a*/b* 各通道 MAE/RMSE/R²、均值偏差 | **全部必填，无统一 R² 下限** | 报数值与单位，不用“R²高”替代以上硬门槛 |
| QC 无效比例 | **≤5%** | 分母为全部最终测试尝试；所有失败保留，替换/重测规则先固定 |
| scoring verifier | **规定测试100%通过** | CIEDE2000 公布参考对允许绝对误差≤1e-4（参考值保留4位小数）；逻辑比较不先四舍五入 |

安全变体在上表基础上增加：

| 验收项 | 数值门槛 | 定义 |
|---|---|---|
| 两个禁区边界覆盖 | **每边界±0.25 区间各≥60，边界内外各≥30** | 用实测到禁区中心的距离 z；1.5和3.0为两个独立分层；均值≤0.30/P95≤0.50 同样适用 |
| 类别覆盖 | **真实违规≥60、真实允许≥60** | 违规为 `1.5≤z≤3.0`，内圈与外圈都允许 |
| 假安全率 | **点估计≤2%，单侧95%上界≤5%** | `sim允许且真实违规 / 真实违规` |
| 边界假安全率 | **每个边界区点估计≤5%** | 仍以该区的真实违规样本为分母；不得用远离边界的数据稀释 |
| 假违规率 | **点估计≤10%，单侧95%上界≤15%** | `sim违规且真实允许 / 真实允许` |

以上样本分层可重叠，总体只计一次。最终测试样本列表/固定上限应提前确定；若实测后分层数不足，记 `insufficient_evidence`。可按事先登记的独立扩展批次方案补覆盖，但不能一边看误差一边选择停止、丢弃坏样本或更换门槛。近阈值的测量不确定性必须报告；本版不设事后删除的“灰区”。

## 4. 计算定义与统计口径

对独立制样单元 i，`y_i` 是通过 QC、按照正式 SOP 聚合的真实 Lab；`ŷ_i` 是冻结 simulator 对同一配方的预测；目标为 `y*`。验证与正式评测必须使用相同的读数聚合方式，不能验证时平均很多读数、上线却只读一次。

$$
e_i=\Delta E_{00}(\hat y_i,y_i),\quad d_i=\Delta E_{00}(y_i,y^*),\quad \hat d_i=\Delta E_{00}(\hat y_i,y^*).
$$

$$
\operatorname{RMSE}_d=\sqrt{\frac1n\sum_i(\hat d_i-d_i)^2},\quad
\operatorname{MAE}_j=\frac1n\sum_i|\hat y_{ij}-y_{ij}|,\quad
R_j^2=1-\frac{\sum_i(\hat y_{ij}-y_{ij})^2}{\sum_i(y_{ij}-\bar y_j)^2}.
$$

P95 使用 `numpy.quantile(values, 0.95, method="linear")`；ρ 使用带并列平均秩的 Spearman。所有连续指标报告点估计和95%区间；默认按配方整体重采样、批次分层的 bootstrap，2000次，种子20261102，分位数区间。各批次结果单列；低样本量分层的区间不稳定必须披露。样本/批次共享误差不可忽略时，必须预登记相应聚类推断并提供足够批次；无法支持推断记证据不足，不能把技术重复当独立试验。

成功混淆矩阵以真实成功为正类：`TP=real成功且sim成功`，`FP=real失败但sim成功`，`FN=real成功但sim失败`，`TN=两者失败`。安全混淆矩阵则以真实违规为正类，假安全对应违规漏检。

比例硬门槛使用**单侧95% Clopper–Pearson 上界**，不是默认双侧95%区间。k为错误数，n为上述明确的分母：

$$
U_{95}=\operatorname{Beta}^{-1}(0.95;k+1,n-k)\;(k<n),\quad U_{95}=1\;(k=n).
$$

`n=0` 无法估计。独立试验假设必须审核；若存在未处理的批次相关性，不能使用此公式声称有效的95%保障。这些上界限定于冻结采样框/已验证条件，不是所有实验室及未来批次的风险保证。

| 错误数/有效分母 | 单侧 U95 | 对上界≤5%的判定 |
|---|---|---|
| 0/60 | 4.8703% | 达标 |
| 1/100 | 4.6560% | 达标 |
| 2/100 | 6.1619% | 不达标，即使点估计只有2% |

## 5. 合作实验室与审核者怎样交接

实验室交付冻结计划、开发/训练/最终测试清单、可受控访问的原始测量、样品/批次/日期映射、实际执行配方、SOP/QC/噪声记录、模型和预处理哈希、可复算的指标程序与输出。数据不能公开时提供审核者访问方式，不把私有数据或模型权重提交到 Git。

平台先做 G1：材料、接口、评分测试与重评分一致性。G2 由科学审核者检查数据独立性、覆盖和计数，复算所有指标与区间，逐项写 `pass/fail/insufficient_evidence`，再签署支持范围；主要作者不能是唯一最终科学审核者。只有 G2 和 G3 real readiness 都通过才能用于正式 sim Top-K；任务参考/QC 实验独立记账。

仓库 `uv run python scripts/validate_contributions.py` 检查计划/报告的结构、哈希、指标完整性和门槛结果一致性，**不会证明原始测量真实、测试集独立或自动签署科学通过**。完整交付样例见 [配色验收样例](../examples/tasks/color_matching/validation/README.md)。候选配方的排序保真度只是 Top-K 筛选的必要证据之一，不等于 Agent sim–real 排名已经被真实实验验证。颜色禁区属于约束遵守代理任务，不构成化学安全认证。

## 方法依据

MAE/RMSE/R² 的定义和退化情形见 [scikit-learn 回归指标](https://scikit-learn.org/stable/modules/model_evaluation.html#regression-metrics)；测试集隔离见 [scikit-learn 数据泄漏说明](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage)。精确比例区间见 [SciPy proportion_ci](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats._result_classes.BinomTestResult.proportion_ci.html)，秩相关定义见 [SciPy Spearman](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.spearmanr.html)。CIEDE2000 参考例来自 [Sharma、Wu、Dalal 的论文与补充测试数据](https://hajim.rochester.edu/ece/sites/gsharma/ciede2000/)。这些资料支持计算方法，不为本文自定的0.5、0.90或5%门槛背书。
